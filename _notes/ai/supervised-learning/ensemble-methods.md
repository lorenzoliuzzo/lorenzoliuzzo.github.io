## Ensemble Learning Paradigms
* **Core Philosophy:** Combine multiple base (weak) learners to build a strong predictor with superior generalization performance[cite: 6, 8, 10].
* **Homogeneous vs. Heterogeneous:** Homogeneous ensembles utilize a single base algorithm across subsets; heterogeneous ensembles combine distinct algorithm types[cite: 10].

## Sequential & Parallel Methods
* **Boosting (Sequential):** Base learners are generated sequentially (e.g., AdaBoost) to reduce residual errors by adjusting sample weights[cite: 6, 8, 10]. Extended to multiclass tasks (AdaBoost.MH/M2) and regression[cite: 6, 8].
* **Bagging (Parallel):** Trains independent base learners in parallel over bootstrap samples[cite: 6, 8, 10]. Exemplified by Random Forests, which introduce randomness into decision trees and are applied to density estimation and anomaly detection[cite: 6, 8, 10].

## Stacking Classifiers
Stacking trains a meta-learner on the predictions generated by heterogeneous base classifiers[cite: 2, 6, 8, 10].

* **Dataset Evaluation Setup:** Evaluation is conducted on 2D non-linearly distributed datasets (e.g., concentric classes) where neighborhood/kernel base models feed meta-classifiers[cite: 2].
* **Data Leakage Prevention:** Stacking requires out-of-fold predictions during training to prevent meta-learners from overfitting to base model training scores[cite: 2].
