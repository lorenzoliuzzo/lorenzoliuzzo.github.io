{% comment %} Where this note sits in its course. Renders nothing; sets variables for the caller: this_course, this_part, part_index the course and part (part_index counts from 1) course_url the course's page, /notes// course_pos, course_total position in the whole course, planned notes included course_prev, course_next neighbouring written notes, for the pager course_next_planned the stub that comes next in the course order, when that next entry is not written yet Courses are _data/courses/.yml, normalised by _plugins/courses.rb, which also gives every part its `items` (key, written, url, title, summary) in reading order. A note belongs to a course when its key is listed in the course's `parts`; the first course that lists it wins. Everything here is a walk over those items: no lookups in site.notes, so the cost per page is the size of one course, not of the whole archive. course_prev, course_next and course_next_planned are items, which have the same url, title and summary a note has. Also sets `here`, the note's key (its path under _notes without the extension). {% endcomment %} {% assign here = page.path | remove_first: "_notes/" | replace: ".md", "" %} {% assign this_course = nil %} {% assign this_part = nil %} {% assign part_index = 0 %} {% assign course_prev = nil %} {% assign course_next = nil %} {% assign course_url = nil %} {% assign course_next_planned = nil %} {% assign course_pos = 0 %} {% assign course_total = 0 %} {% for course in site.data.courses %} {% unless this_course %} {% assign counted = 0 %} {% for part in course.parts %} {% assign pi = forloop.index %} {% for item in part.items %} {% assign counted = counted | plus: 1 %} {% if item.key == here %} {% assign this_course = course %} {% assign this_part = part %} {% assign part_index = pi %} {% assign course_pos = counted %} {% endif %} {% endfor %} {% endfor %} {% endunless %} {% endfor %} {% if this_course %} {% assign course_url = this_course.url %} {% assign seen_here = false %} {% assign just_after = false %} {% assign immediate = nil %} {% for part in this_course.parts %} {% for item in part.items %} {% assign course_total = course_total | plus: 1 %} {% if item.key == here %} {% assign seen_here = true %} {% assign just_after = true %} {% elsif seen_here == false %} {% if item.written %}{% assign course_prev = item %}{% endif %} {% else %} {% if just_after %}{% assign immediate = item %}{% assign just_after = false %}{% endif %} {% if item.written and course_next == nil %}{% assign course_next = item %}{% endif %} {% endif %} {% endfor %} {% endfor %} {% if immediate and immediate.written == false %}{% assign course_next_planned = immediate %}{% endif %} {% endif %}
