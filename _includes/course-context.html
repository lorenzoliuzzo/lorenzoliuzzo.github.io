{% comment %} Where this note sits in its course. position — "top" renders the strip above the text. "data" renders nothing and leaves `this_course`, `this_part`, `course_url`, `course_prev` and `course_next` set for the caller (post_pagination.html uses them for the pager). Courses are _data/courses.yml. A note belongs to a course when its path is listed in the course's `parts`; the first course that lists it wins. Reading order is the order of `parts`, limited to published notes (a planned note has no page to link to).
