{% comment %} A list of the page's figures and tables, in document order, numbered to match the CSS counters in _sass/_academic.scss. Built from the DOM rather than from Liquid: the floats come from {% include figure.html %} / {% include table.html %} calls scattered through a note's Markdown body, which this include has no way to enumerate. Drop it anywhere in a note — usually just under the intro. It renders nothing at all on a page with no floats, so it is safe to leave in place while a note is still being written. Each group is omitted on its own, so a note with figures and no tables gets just the one heading. {% endcomment %}
