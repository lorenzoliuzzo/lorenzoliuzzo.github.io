{% comment %} Title filter for a grouped archive. Hides non-matching rows, then folds away any subsection or section left with nothing in it, so the page never shows an empty heading. Progressive enhancement: without JS the full index is there. Written notes and planned ones are both filterable rows. Matching on .entry-card alone would fold away every subsection holding only planned topics — Optics, Particles, and the whole Logic and Statistics sections — on page load, with no filter typed. This lives in an include rather than inline in _pages/notes.md because kramdown rewrites the script body when it sits in a Markdown file — with mathjax on it backslash-escapes parentheses, pipes and underscores, which is a syntax error. {% endcomment %}
