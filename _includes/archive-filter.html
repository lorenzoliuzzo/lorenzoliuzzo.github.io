{% comment %} Title filter for a grouped archive. Hides non-matching cards, then folds away any subsection or section left with nothing in it, so the page never shows an empty heading. Progressive enhancement: without JS the full index is there. This lives in an include rather than inline in _pages/notes.md because kramdown rewrites the script body when it sits in a Markdown file — with mathjax on it backslash-escapes parentheses, pipes and underscores, which is a syntax error. {% endcomment %}
