{% comment %} Title filter and subtopic folding for a grouped archive. The filter hides non-matching rows, then folds away any subsection or section left with nothing in it, so the page never shows an empty heading. Progressive enhancement: without JS the full index is there and every
ships open. Written notes and planned ones are both filterable rows. Matching on .entry-card alone would fold away every subsection holding only planned topics — Optics, Particles, and the whole Logic and Statistics sections — on page load, with no filter typed. Filtering and folding live in one script because they fight over the same bit: a match inside a collapsed subtopic has to win, so the filter overrides the reader's folds for as long as it is active and hands them back after. The library includes this too, and groups without foldable subtopics; every fold branch below is inert when the page has no
. This lives in an include rather than inline in _pages/notes.md because kramdown rewrites the script body when it sits in a Markdown file — with mathjax on it backslash-escapes parentheses, pipes and underscores, which is a syntax error. {% endcomment %}
